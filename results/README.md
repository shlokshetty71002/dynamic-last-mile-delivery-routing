# Generated results

Generated outputs are ignored because every number must derive from committed code, instance,
scenario, configuration, and seed. Keep selected evidence outside this directory only when it is
explicitly labelled and regenerated by a documented target.

## Output contracts

- `dlm plan`: JSON with solver, drive/service/total seconds, metres, orders, loads, and metadata.
- `dlm compare`: `result.json`, interactive `comparison.html`, `comparison.png`, and
  `comparison.svg`.
- `Experiment.write`: byte-stable `result.json` and complete `config.yaml` under its hashed run ID.
- `dlm batch`: tidy `summary.csv` (one run per row) and grouped `statistics.json`.
- `dlm figures`: colourblind-safe PNG and vector SVG generated only from the tidy CSV.

Runtime telemetry (`wall_time_ms`) is observational and may vary; scientific input/result fields
are deterministic for the same graph cache and configuration.
