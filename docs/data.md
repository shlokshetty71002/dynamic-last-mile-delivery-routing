# Data provenance and assumptions

## Road network

The live graph is requested through OSMnx 2.1.x from OpenStreetMap using
`network_type="drive"`, `simplify=true`, and WGS84 bbox
`(west=-6.50, south=53.20, east=-6.05, north=53.47)`. This rectangle is an explicit,
reproducible envelope for the M50 catchment; it is not claimed to be the motorway polygon.
OSMnx returns a directed `MultiDiGraph`, and the loader retains the largest strongly connected
component before annotating travel time.

The GraphML filename is a SHA-256-derived key over every construction input, OSMnx version, cache
schema, and speed table. Adjacent JSON metadata records UTC access time, versions, bbox, and graph
statistics. OSM is a living database: deleting the cache and rebuilding later can legitimately
change counts or paths. Preserve a run's metadata when exact historical reproduction matters.

Road data and map tiles are © OpenStreetMap contributors, licensed under the Open Data Commons
Open Database License. Attribution requirements and legal terms are on the
[official OSM copyright page](https://www.openstreetmap.org/copyright). OSMnx's
[`graph_from_bbox` documentation](https://osmnx.readthedocs.io/en/stable/user-reference.html#osmnx.graph.graph_from_bbox)
describes the API and directed network types.

## Edge speed policy

An interpretable numeric `maxspeed` tag is used when present. Otherwise the committed
`src/dlm/network/irish_speed_defaults.yaml` table supplies kilometres per hour:

| Highway class | km/h | Highway class | km/h |
|---|---:|---|---:|
| motorway | 100 | motorway link | 80 |
| trunk | 80 | trunk link | 60 |
| primary | 60 | primary link | 50 |
| secondary/tertiary | 50 | links | 50 |
| residential/unclassified/road | 50 | living street/service | 20 |
| unknown fallback | 50 |  |  |

These are modelling defaults by OSM road class, not assertions that each physical road currently
has that legal limit. Irish limits are changing: the Department of Transport states that the
rural local-road default moved from 80 to 60 km/h in February 2025 and describes subsequent
urban reductions on its [Slower Speeds programme](https://www.gov.ie/en/department-of-transport/campaigns/slower-speeds-safer-roads/).
The project therefore prioritises an explicit OSM `maxspeed` whenever available and reports the
observed-versus-imputed percentages.

Travel time is `3.6 × length_m / speed_kph`, in seconds. No live congestion multiplier, signal
delay, parking/search time, or stochastic speed is inferred.

## Locations and instances

`data/presets/dublin_locations.yaml` contains 46 recognisable Dublin universities, hospitals,
retail areas, transport/logistics locations, landmarks, and suburbs. Coordinates are WGS84
reference points prepared for this model and are always snapped to a routable graph node with a
default 500 m guard. They are not property boundaries or delivery entrances.

The N=8, N=20, and N=40 report instances are schema-versioned JSON generated by
`scripts/generate_report_instances.py`. They record location source, demand, service time, seed,
and creation timestamp. Node IDs remain null deliberately so the same file can resolve against a
new OSM snapshot without embedding stale graph identity.

Addresses use Nominatim through OSMnx with an on-disk query cache. Ambiguous results return
candidates instead of selecting the first; users are responsible for choosing the intended place.

## Disruption scenarios

The four committed YAML files are versioned **modelling scenarios** representing plausible
Dublin event/works/bridge patterns. Geometry and street names are inputs selected for simulation;
they are not evidence that an event occurred at a claimed date, and they are never live notices.
Each source field states that limitation. Random closures are sampled from sorted edges with an
explicit seed.

## Sustainability factors

The default direct diesel factor is 2.68 kg CO₂/L, rounded from SEAI's current petroleum
diesel/gasoil value of 2.682 kg CO₂/L. SEAI explicitly notes that this is combustion-only and
excludes extraction, processing, and transport; see
[SEAI conversion factors](https://www.seai.ie/data-and-insights/seai-statistics/conversion-factors).
Fuel efficiency and price are model configuration assumptions recorded with each experiment.
